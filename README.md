# GCDBar

GCDBar is a lightweight World of Warcraft addon that displays a Global Cooldown (GCD) bar to help visualize ability cooldown timing in another way

**Features**
- Simple GCD Bar
- Configurable position and appearance via the AddOns options

**Installation**
1. Place the `GCDBar` folder into your WoW AddOns directory (e.g., `Interface/AddOns/`).
2. Log into World of Warcraft and enable the addon from the AddOns menu, or reload the UI with `/reload`.

**Usage**
- Configure the addon via the in-game AddOns options: `Interface -> AddOns -> GCDBar`.
